# 🛡️ Security Write-ups & Technical Documentation

Dokumentasi analisis keamanan informasi, laporan pengujian penetrasi terstruktur, serta catatan riset teknis mengenai keamanan aplikasi web, jaringan, dan konfigurasi sistem.

---

## 🎯 Objectives & Focus Areas

Repositori ini bertujuan untuk mendokumentasikan metodologi analisis keamanan dan langkah-langkah mitigasi risiko secara sistematis. Fokus utama pengujian meliputi:

* **Web Application Security:** Identifikasi kerentanan (*OWASP Top 10*), pengujian sanitasi input, dan analisis logika otentikasi.
* **Network & Infrastructure Assessment:** Analisis lalu lintas jaringan, identifikasi port/layanan terbuka, serta evaluasi konfigurasi sistem.
* **System Hardening & Forensics:** Analisis artefak sistem, audit hak akses, dan rekomendasi langkah remidiasi.
